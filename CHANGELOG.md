# Changelog

All notable changes to **Notes Web App** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-29

### Added
- **Frontend Architecture**: Fast, modern React 18 application scaffolded with Vite and TypeScript.
- **UI Design System**: Sleek glassmorphism inspired by Web Database Viewer with Outfit font, Phosphor/Lucide icons, and light/dark theme persistence.
- **Backend Architecture**: High-speed Fastify TypeScript API server with CORS and Multipart support.
- **Database Layer**: Lightweight MySQL database models and migrations powered by Drizzle ORM.
- **Image Attachments**: Backblaze B2 S3 storage integration for direct drag-and-drop, clipboard paste, and presigned uploads.
- **Interactive Markdown Editor**: Split view note editor with live markdown preview, formatting toolbar, and inline image linking.
- **Attachment Drawer & Modal**: Value inspector for image preview, metadata inspection, and deletion.
- **Search & Filtering**: Real-time multi-tag filtering, keyword search, and pinned/archived views.
- **Command Palette**: Keyboard-driven navigation with `⌘K` / `Ctrl+K`.
- **Documentation Suite**: Comprehensive README, Contributing, Code of Conduct, Security, and Changelog documents.
