# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Notes Web App**, please do NOT open a public issue. Instead, report security concerns directly to the project maintainers.

Please include:
* Description of the potential vulnerability.
* Detailed steps to reproduce.
* Potential impact and attack vectors.

We appreciate your effort in responsibly disclosing issues and will respond promptly to patch verified vulnerabilities.
